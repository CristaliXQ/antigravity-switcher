# Antigravity Account Switcher

Утилита для управления профилями и мгновенного переключения между Google-аккаунтами в Google Antigravity без повторного ввода паролей.

## Расположение
- Исполняемый файл на рабочем столе: `C:\Users\denis\Desktop\Antigravity Switcher.exe`
- Исходный код и проект: `C:\Users\denis\Desktop\gemini work\antigravity_switcher\`
- База сохраненных профилей: `%APPDATA%\Antigravity\antigravity_accounts.json`

## Ключевые исправления
1. **Устранение серого экрана**: В ярлыке Antigravity на рабочем столе и в меню «Пуск» прописан флаг подключения через локальный прокси (`--proxy-server="socks5://127.0.0.1:10807"` для v2RayTun). Утилита автоматически считывает аргументы из ярлыка и запускает Antigravity с ними. Без этого флага интерфейс Antigravity не может подключиться к серверам Google и зависает серым экраном.
2. **Мгновенное переключение (Fast Switch)**: Убраны блокирующие искусственные задержки (до 4.5 секунд). Процессы глушатся за миллисекунды, перезапись токенов и запуск занимают суммарно менее 150 мс.
3. **Без лишних диалогов**: При нажатии кнопки или двойном клике по аккаунту в списке переключение происходит мгновенно.

## Сценарии использования
- **Сохранить текущий**: Кнопка «💾 Сохранить» сохраняет активный токен в список профилей.
- **Добавить новый аккаунт**: Кнопка «➕ Добавить через вход» сбрасывает активную сессию и запускает Antigravity (с прокси). После входа через браузер программа автоматически сохранит второй аккаунт.
- **Переключить**: Двойной клик по строке в списке или кнопка «⚡ ПЕРЕКЛЮЧИТЬ И ПЕРЕЗАПУСТИТЬ».
